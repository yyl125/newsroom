站点资源域名即将转移至 Cloudflare

2026-02-17 2 min read # 新闻稿

站点资源域名 yyl125.cc 注册商即将由 Alibaba Cloud 转移至 Cloudflare

更新

站点资源域名注册商已于北京时间 2026 年 2 月 24 日成功转移至 Cloudflare

Benjamin 已向站点资源域名 yyl125.cc 的原注册商 Alibaba Cloud 申请将域名注册商转移至 Cloudflare，预计将在 5-7 天后自动完成转出

在大多数情况下，转移域名时，将自动将额外一年添加到当前到期日期。注册机构负责确定何时添加额外一年，并在某些情况下可能不会添加一年：

  • 如果域名在到期日期后 45 天内转移，注册机构可能不会添加额外一年；
  • 如果当前到期日期超过 9 年，注册机构可能只会添加部分一年

此外，由于相关 DNS 解析并未做出任何更改，相关站点请求理应无任何显性问题。但由于技术原因或其它不确定性，在转移期间，Benjamin 所有站点资源类请求可能遇到随机问题，敬请谅解

以下是可能涉及到的相关请求：

  1. Benjamin 所有站点的媒体类资源请求，如图片、视频以及其它静态资源文件；
  2. Benjamin' Blog 的「随想」、「记录」板块；
  3. 合作交流联系邮箱 hi@yyl125.cc 以及技术支持与反馈联系邮箱 support@yyl125.cc；
  4. 其它未列明但可能有影响的内容

转移期间，如需任何帮助，请通过 Benjamin 所留的其它任何联系方式予以联系
